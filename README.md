## TIFF2PDF
> [!IMPORTANT]
> **Disclaimer:** This application was built with AI-generated code. If you prefer not to use AI-generated software, please do not proceed. 

### About
- Simple and portable application to recursively scan through a folder for TIF/TIFF files. Once run it converts them to PDF, OCRs the contents, and rotates pages for readability. 
- Multi-threaded with core control (select how many CPU threads to use).

### Installation
Download the .zip file which contains all required dependencies. Run TIFF2PDF.exe

### Dependencies
- [7-Zip](https://www.7-zip.org/)
- [ImageMagick](https://github.com/ImageMagick/ImageMagick)
- [Poppler](https://github.com/innodatalabs/poppler)
- [qpdf](https://github.com/qpdf/qpdf)
- [Tesseract](https://github.com/tesseract-ocr/tesseract)
